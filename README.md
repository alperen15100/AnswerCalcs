# AnswerCalcs

Premium everyday calculators, countdowns and date tools with a bounded programmatic-SEO architecture.

## GitHub Pages
This repository is configured to build and deploy automatically with GitHub Actions.

Preview URL:
https://alperen15100.github.io/AnswerCalcs/

The current launch build creates crawlable static pages for:
- How long until HH:MM
- Days from today
- Weeks from today
- Hours from now
- Christmas, Halloween and New Year countdowns
- Percentage, tip, age, business-days, date-difference and time-zone calculators

SEO foundations included:
- sitemap.xml
- robots.txt
- canonical URLs
- JSON-LD
- internal linking
- llms.txt
- direct-answer content blocks

When a custom domain is purchased, update BASE_PATH and SITE_URL in .github/workflows/pages.yml.
